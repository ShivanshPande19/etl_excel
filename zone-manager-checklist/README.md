# ETL — Zone Manager Court Checklists

Print-ready checklists that each **Zone Manager** fills in for **their own food court**
and hands to the **Operations Manager**. Derived from the ETL Operations SOP and kept at
the floor level (what the Zone Manager personally checks), not as a management report.

There are two sheets: a short **daily** one and a **weekly** one for the items that do
not change every day.

## Daily checklist — `ETL/OPS/ZM/DC-01`, Rev 2.0 (3 pages)

| File | What it is |
|------|------------|
| `ETL-Zone-Manager-Daily-Checklist.pdf` | The printable daily form. **Print this** (3 A4 pages). |
| `zone-manager-daily-checklist.html` | Editable source. Open in a browser and `Ctrl/Cmd + P` to print or Save as PDF. |
| `preview/page-1.png` … `page-3.png` | Page images for a quick look. |

**Contents (15 sections):**
1. **Page 1** — Court info, opening readiness, staff attendance, utilities & power, housekeeping rounds.
2. **Page 2** — Washroom check (every 2 hours), maintenance walk, open-issue list, security check, outlets (space for 6).
3. **Page 3** — Customer experience round, complaints, collections received today, incidents, closing & night handover, points for the Operations Manager, sign-off.

## Weekly checklist — `ETL/OPS/ZM/DW-01`, Rev 1.0 (1 page)

| File | What it is |
|------|------------|
| `ETL-Zone-Manager-Weekly-Checklist.pdf` | The printable weekly form (1 A4 page). |
| `zone-manager-weekly-checklist.html` | Editable source. |
| `preview-weekly/page-1.png` | Page image. |

**Contents:** outlet licence & safety audit (FSSAI, trade licence, fire extinguisher,
first aid, pest control, staff medical cards), stock & consumables, weekly safety drill
& preventive maintenance, and a short week summary. These items were moved off the daily
sheet so the daily sheet stays light.

## Notes

- Outlet rows: the daily sheet and the weekly audit each have **space for 6 outlets**.
  Add or remove rows in the HTML if a court has more or fewer.
- Golden rule printed on the form: *tick only what you have personally seen, not what
  staff told you.* A blank box is read as **NOT DONE**; write **NIL** where there is
  nothing to report.
- Serious incidents (fire, injury, theft, food poisoning) must be **phoned to the
  Operations Manager at once** — do not wait for the sheet.

## How to edit / re-print

Open the HTML file in any browser and use the print dialog (A4, Default margins,
Background graphics ON), then Print or Save as PDF.
