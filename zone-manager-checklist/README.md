# ETL — Zone Manager Daily Court Checklist

Form No. **ETL/OPS/ZM/DC-01**, Rev 1.0

A print-ready daily checklist that each **Zone Manager** fills in for **their own food
court** and hands to the **Operations Manager** every morning. It is derived from the
ETL Operations SOP and works at the floor level (what the Zone Manager personally
checks), not as a management report.

## Files

| File | What it is |
|------|------------|
| `ETL-Zone-Manager-Daily-Checklist.pdf` | The printable form. **Print this** (5 A4 pages). |
| `zone-manager-daily-checklist.html` | Editable source. Open in a browser and `Ctrl/Cmd + P` to print or Save as PDF. |
| `preview/page-1.png` … `page-5.png` | Page images, for a quick look without opening the PDF. |

## What's inside (19 sections over 5 pages)

1. **Page 1** — Court info, opening readiness (20 checks), staff attendance, utilities & power.
2. **Page 2** — Housekeeping rounds, washroom hourly check (09:00–23:00), maintenance walk, open-issue list.
3. **Page 3** — Security check, **my outlets** (space for 6 outlets), customer experience round.
4. **Page 4** — Customer complaints, collections received today, licence & safety spot check, events, tomorrow's follow-ups.
5. **Page 5** — Incidents, stock, closing & night handover, vendor discussion minutes, points for the Operations Manager, sign-off.

## Notes

- Outlet section has **6 name rows**. If a court has more or fewer outlets, add or
  remove rows in the HTML (Section 9) and re-print.
- Golden rule printed on the form: *tick only what you have personally seen, not what
  staff told you.* A blank box is read as **NOT DONE**; write **NIL** where there is
  nothing to report.

## How to edit

Open `zone-manager-daily-checklist.html` in any browser. To regenerate the PDF, use the
browser's print dialog (A4, Default margins, Background graphics ON) and Save as PDF.
