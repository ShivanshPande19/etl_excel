# Staff photos

Place each staff member's photo here using their **slug** as the file name.
The ID cards (`etl-id-cards.html`) load photos from this folder automatically.

| Person | File name (any of these extensions work) |
|---|---|
| Deepak | `deepak.jpg` |
| Delip | `delip.jpg` |
| Anshu | `anshu.jpg` |
| Sunil | `sunil.jpg` |
| Vansh Singh Fartyal | `vansh.jpg` |

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.
A roughly portrait (3:4) photo looks best. Until a photo is added, that card shows a "PHOTO" placeholder.
