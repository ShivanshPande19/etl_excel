# Logo asset

Place the official ETL logo here with this **exact** file name:

```
assets/etl-logo.png
```

The ID cards (`etl-id-cards.html`) load the logo from this path for both the header badge
and the background watermark. Until the real file is added, the cards show a vector (SVG)
fallback that closely resembles the logo.

A transparent-background PNG (or a square PNG) works best.
